# vetsvg

Vet list/svg set operations for shell-friendly data wrangling.

**Site:** https://theworker02.github.io/vetsvg/

## Install / run

```bash
git clone https://github.com/theworker02/vetsvg.git
cd vetsvg
node src/cli.js
node --test
```
